# Larvik Beach Volley

Nettside og spleise-app for beachvolley-gjengen i Larvik. Spillerne melder seg på økter,
hallprisen deles på de som var med, og hver får én regning i måneden som betales med Vipps.

Stack: Vite + React + TypeScript, Supabase (Postgres, e-postkode-innlogging, RLS, pg_cron,
Edge Functions), Resend, Netlify. Design etter Wispr Flow-systemet (cream, ink, lavender).

Oppsett og drift: `supabase/SETUP.md`.
